# Optical-Convolution-Experiment-Image-Generator

Keysight M8195A AWG（任意波形発生器）を用いて、MNISTの手書き数字画像を送信するためのアナログ波形データ（バイナリ）を生成するMATLABパッケージです。
光畳み込み実験の送信側（TX）にあたります。

## 概要
本プログラムは、GitHubでのバージョン管理や複数人開発を容易にするため、設定・入出力・画像処理・信号処理を独立したパッケージ（`+config`, `+io`, `+image`, `+signal`）としてモジュール化しています。

**主な特徴:**
- **層化抽出と完全な再現性:** 過去の `idxEval.mat` に依存せず、MNISTデータから0〜9の数字を均等にランダム抽出します。乱数シードを固定しているため、環境を問わず常に同一の波形が生成されます。
- **柔軟なペイロード生成:** ピクセル値のN-bit量子化、MSB/LSBシリアライズ、多値シンボル化に対応。
- **畳み込み用並び替え:** 2x2畳み込み実験に向けた独自の画素順序（27行×28列のオーバーラップ順序）をサポート。

## ディレクトリ構造

```text
conv_generate/
├── +config/          # 設定パラメータ管理 (getDefaultConfig.m)
├── +io/              # MNIST均等抽出、波形・メタデータのファイル入出力
├── +image/           # 画像の量子化・ピクセル順序の並び替え
├── +signal/          # プレアンブル生成、シンボルマッピング、パディング
├── data/             # 入出力データの格納用ディレクトリ (.gitignore対象)
│   ├── input/        # (必要に応じて外部入力データを配置)
│   └── output/       # 生成された .bin や .csv が出力される
├── main.m            # メイン実行スクリプト
├── .gitignore        # 大容量バイナリ等の除外設定
└── README.md         # 本ドキュメント
